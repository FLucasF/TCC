FUNCIONALIDADES IMPLEMENTADAS:

✅ QUARTOS (5 unidades, 3 tipos)
   - 101, 102: STANDARD (2 pax) - R$ 249,90/noite
   - 201, 202: DELUXE (3 pax) - R$ 389,90/noite
   - 301: SUITE (4 pax) - R$ 579,90/noite

✅ ALTA TEMPORADA
   - 15/12 a 28/02 (verão)
   - Julho inteiro
   - Multiplicador: +20% por noite

✅ PLANOS DE TARIFA
   - STANDARD: Preço cheio, reembolso 100% se STANDARD
   - NON_REFUNDABLE: -15% desconto, sem reembolso

✅ ARREDONDAMENTO
   - HALF_EVEN (meia para o par)
   - 4 pontos: noite, subtotal, desconto, total

✅ CICLO DE VIDA
   - PENDING → CONFIRMED → CHECKED_IN → CHECKED_OUT
   - CANCELLED (com reembolso condicional)

✅ VALIDAÇÕES
   - Capacidade do quarto vs hóspedes
   - Datas (check-out > check-in)
   - Conflitos de booking (por noite)

✅ COMPROVANTES
   - Formatação em português (datas dd/MM/yyyy)
   - Valores formatados em R$ X.XXX,XX
   - Nº sequencial por reserva

✅ EMAILS
   - Assunto: "Reserva confirmada - Pousada Maré Alta"
   - Corpo com dados de entrada/saída
   - Comprovante integrado
   - Armazenado em banco para auditoria

✅ 4 RELATÓRIOS CSV
   1. Ocupação (por noite)
   2. Financeiro (por mês, net de reembolsos)
   3. Taxa Turística (R$ 4,50 × hóspedes × noites)
   4. Análise de Planos (STANDARD vs NON_REFUNDABLE)

✅ API REST
   - 14 endpoints (GET/POST)
   - Tratamento de erros HTTP padronizado
   - Status codes apropriados (201, 400, 404, 409, 422)
   - JSON com 2 casas decimais em dinheiro

✅ BANCO DE DADOS
   - PostgreSQL 18
   - 3 tabelas: rooms, reservations, messages
   - Índices para performance
   - Auto-criação de schema

COMO USAR:

1. COM DOCKER COMPOSE (MAIS FÁCIL)
   docker-compose up
   Acesse: http://localhost:7070

2. MANUALMENTE
   mvn clean package
   export DB_URL="jdbc:postgresql://localhost:5432/pousada"
   export DB_USER="pousada"
   export DB_PASSWORD="senha"
   java -jar target/app.jar

3. TESTAR
   ./test-api.sh
