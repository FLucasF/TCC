================================================================================
QUICK START
================================================================================

1. Compilar:
   mvn clean package

2. Com Docker Compose:
   docker-compose up

3. Sem Docker (manual):
   export DB_URL="jdbc:postgresql://localhost:5432/pousada"
   export DB_USER="pousada"
   export DB_PASSWORD="senha123"
   export PORT=7070
   java -jar target/pousada-mare-alta-1.0.0.jar

4. Testar API:
   bash test-api.sh

================================================================================
FUNCIONALIDADES IMPLEMENTADAS
================================================================================

✓ 5 quartos com tipos (STANDARD, DELUXE, SUITE) e capacidades
✓ Detecção de alta temporada (15/12-28/02 + julho) com 20% acréscimo
✓ 2 planos de tarifa (STANDARD com reembolso, NON_REFUNDABLE com 15% desconto)
✓ 3 tipos de documento (Comprovante CPF, Fatura CNPJ, Booking Receipt)
✓ Fluxo de estado: PENDING → CONFIRMED → CHECKED_IN → CHECKED_OUT
✓ Cancelamento com reembolso condicional
✓ E-mail de confirmação com documento
✓ Arredondamento "meio para o par" (banker's rounding)
✓ Validação de disponibilidade de quartos
✓ Validação de capacidade
✓ Relatório de ocupação em CSV
✓ Relatório financeiro em CSV
✓ Tudo em PostgreSQL 18 com Javalin 6.7.0
