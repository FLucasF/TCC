========================================
ARQUITETURA DO SISTEMA DE MENSAGENS
========================================

Pipeline de Processamento:

  Mensagem Original
       ↓
  EmailValidationRule
       ↓ (se válido)
  TestModeRule
       ↓ (modifica se test mode)
  ArchiveCopyRule
       ↓ (gera cópia se não test mode)
  Salva todas as mensagens

Características:
  ✅ Extensível (Chain of Responsibility)
  ✅ Cada regra é independente
  ✅ Fácil adicionar novas regras
  ✅ Ordem de execução controlada
  ✅ Contexto compartilhado
  ✅ Mensagens adicionais suportadas
  ✅ Bloqueio de mensagens

========================================
COMO EXECUTAR
========================================

1. Iniciar PostgreSQL:
   docker run --name pousada-db \
     -e POSTGRES_DB=pousada \
     -e POSTGRES_USER=postgres \
     -e POSTGRES_PASSWORD=postgres \
     -p 5432:5432 \
     -d postgres:18

2. Configurar variáveis:
   export DB_URL=jdbc:postgresql://localhost:5432/pousada
   export DB_USER=postgres
   export DB_PASSWORD=postgres
   export PORT=7070
   export HOTEL_TEST_MODE=false

3. Build:
   mvn clean package

4. Executar:
   java -jar target/reservas-1.0.0.jar
   
   Ou:
   ./START.sh

5. Testar:
   curl http://localhost:7070/rooms
