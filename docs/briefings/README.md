# Briefings

Documentos que dirigiram ou informaram o harness. Os marcados **deprecated** no nome
já foram executados ou superados: valem como registro, não como guia, e cada um diz
no topo por quê. Antes de planejar algo novo, leia `decisoes-do-harness.md`; é o
único que é mantido.

| Arquivo | Estado | O que é |
|---|---|---|

| `varredura-harnesses.md` | vigente, referência (05 e 06/09) | Levantamento de 72 repositórios de harness. Corrigido em oito pontos pela análise |
